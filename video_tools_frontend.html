Video Tools Offline

Converte vídeos de vários formatos para MP4 leve e compatível com celulares, direto no navegador. Seus arquivos não são enviados para nenhum servidor.

⬇️ Baixar resultado

Na primeira conversão, é necessário baixar o mecanismo FFmpeg (cerca de 30 MB). A conversão acontece no aparelho e pode demorar; vídeos muito grandes podem exceder a memória disponível, especialmente em celulares.

📘 Como instalar e usar offline

Celular/tablet (recomendado): 1) abra o endereço do site (https) no Chrome, com internet; 2) toque em Preparar para usar offline e espere terminar (~30 MB); 3) menu ⋮ → Adicionar à tela inicial/Instalar app; 4) pronto, abre sem internet. Não limpe os dados do navegador, senão o offline some.

Computador: 1) clique em Baixar e salve os 2 arquivos na mesma pasta (permita múltiplos downloads); 2) abra o terminal nessa pasta e rode python -m http.server 8080 (ou use a extensão Live Server do VS Code); 3) abra http://localhost:8080/video_tools_frontend.html com internet e clique em Preparar para usar offline; 4) depois funciona sem internet, com o servidor local ligado. Dar duplo clique no arquivo (file://) não ativa o offline.

Recomendações: use Chrome/Edge atualizado; prefira vídeos de até ~1 GB (acima disso pode faltar memória); no celular use 480p e deixe a tela ligada no carregador; para só trocar de MKV para MP4 use a opção rápida (não recodifica); no corte "rápido" o ponto de corte pode variar 1–2 s.
